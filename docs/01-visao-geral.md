# Visão Geral

Nome provisório:
CatalogPro

Missão:
Permitir que pequenos comerciantes criem catálogos digitais profissionais sem precisar de site próprio.

Problema:

Muitos vendedores utilizam apenas:
- WhatsApp
- Instagram
- Facebook

Essas plataformas não organizam produtos de forma eficiente.

Solução:

Uma plataforma onde o comerciante:

- cria conta
- cadastra produtos
- recebe um link exclusivo

Exemplo:

catalogpro.com/minhaloja

O cliente acessa e visualiza:

- produtos
- preços
- descrição
- contato WhatsApp

Objetivo principal:

Transformar visitantes em clientes.
